# Ghofran-BD

تقرير تطوير الأعمال (BD Report) لفلك القابضة: مراجعة العروض الفنية المقدمة، ومعايير القبول، والأسباب المتوقعة، والمشكلة والحل، ونظام ضمان القبول، ودراسة سوق الرياض، وخطة توسيع نطاق الخدمات.

BD Report for Falak Holding: technical proposal review, acceptance criteria, likely reasons, problem and solution, acceptance system, Riyadh market study, and service expansion plan.

- `index.html`: the interactive report (Arabic / English, light / dark)
- `pdf/BD-Report-AR.pdf`, `pdf/BD-Report-EN.pdf`: print versions
